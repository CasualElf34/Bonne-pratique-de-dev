# Bonnes Pratiques de Dev - Exercices Ynov

Exercices du cours de Bonnes Pratiques de Développement à Ynov Campus Montpellier.

## 📁 Les ateliers

### DRY (Don't Repeat Yourself)
`DRY/` - Éliminer la duplication de code  
Une liste de produits avec filtres → refactoriser pour éviter de copier-coller

### KISS (Keep It Simple, Stupid)  
`KISS/` - Garder le code simple  
Une todo-list sur-complexe → la simplifier sans changer le résultat

### SOLID - Dependency Inversion  
`SOLID-Dependency-Inversion-Principe/` - Découpler le code  
Un service d'email couplé à SendGrid → dépendre d'une abstraction

### SOLID - Open/Closed  
`SOLID-Open-Close/` - Extensible sans modifier  
Frais de livraison avec des if/else → pattern Strategy

**Des exercices pour apprendre à écrire du meilleur code !**
